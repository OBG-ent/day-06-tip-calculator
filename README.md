# 🧾 Tip & Split Calculator

**End the "who owes what" debate at the dinner table in under 30 seconds.**

A clean, mobile-friendly web app: type the bill, pick a tip, choose how many people are splitting — and get the per-person total instantly, with a one-tap "copy breakdown" button for the group chat.

## ✨ Features

- 💵 Live calculation as you type — no submit button needed
- 🎯 Tip presets (10% / 15% / 18% / 20% / 25%) plus a custom slider up to 50%
- 👥 People stepper to split the bill any number of ways
- 📋 **Copy breakdown** button — paste the split straight into the group chat
- 🌙 Dark, modern UI that works great on phones at the restaurant

## 🚀 Run it in 30 seconds

No build tools, no dependencies — it's a single HTML file.

1. Download `index.html`
2. Double-click it — it opens in your browser
3. Type the bill amount and watch the math happen live

## 🎮 What you'll see

A dark card with the bill input at the top, tip preset buttons with a custom slider, a − / + stepper for the number of people, and a green results panel showing **tip amount**, **total bill**, and the big number: **each person pays**.
